## Why this analysis matters: user drop-off

**Definition:** User drop-off is the point where visitors leave a website or app before completing a goal such as a purchase or sign-up.
**Class example:** The class opened by looking at how certain images and page layouts could be causing users to drop off.
**Business example:** E-commerce players like Myntra and Flipkart run A/B tests on product images and page layouts and track where users exit the funnel, so they can fix the pages that lose the most buyers.
**Remember:** Drop-off is found with data, and fixed with design. Analytics tells you *where* users leave; testing tells you *why*.

## Web scraping

### Purpose and output

**Definition:** Web scraping is the automated collection of data from web pages. The goal is a clean, structured **CSV file** that you can pre-process and analyse.
**Class example:** After the imports ran successfully, the next step was to give the program a web page URL. The code then works out how much data and how many results that page holds.
**Business example:** Indian price comparison sites like Smartprix track product prices across Amazon.in and Flipkart by collecting listing data repeatedly, then show users price history and the cheapest seller.
**Exam tip:** Always state the end product. In this course, the output of data collection is a CSV file ready for pre-processing.

### The extraction funnel

**Definition:** Extraction follows a funnel: observe the page, capture its structure (the HTML elements and their tags or CSS classes), pull out the raw text, then parse out the specific data points you need.
**Class example:** The faculty called the captured page structure "CST" (likely the HTML/CSS structure of the page, i.e. the DOM tree). From that, the code captured:
- **Text** of each product, the main raw source
- **Price**, isolated from the text
- **Stock availability**, whether the item is in stock

The logic counted how many goods were on the **first page** and printed only the **first five rows** (the head of the data, `df.head()`).
**Business example:** A D2C brand like boAt can monitor competitor listings for price and "out of stock" status to spot when a rival runs short and adjust its own ads or prices.
**Remember:** Text first, then price, then stock. Check your result with `head()` before scraping more pages.

### Pagination

**Definition:** Pagination limits the number of records shown per page, so a large list is split across many pages.
**Class example:** The site showed **20 items per page**. You request a specific URL to get the response for a range, such as items **1 to 20**, then move to the next page URL for the next 20. The first version of the code only scraped page one.
**Business example:** Amazon.in search results and Flipkart category pages are paginated, so any scraper or crawler has to loop through page numbers in the URL to collect the full catalogue.
**Formula:** Number of pages = Total records / Records per page (round up). For example, 1,000 books / 20 per page = 50 pages.
**Exam tip:** Mention that scraping only page one gives a sample, not the full dataset. A loop over page URLs fixes this.

## Data cleaning and pre-processing

### Data type conversion

**Definition:** Scraped values often arrive as text (characters). You must convert them to numbers before you can add, average or sort them.
**Class example:** Prices were stored as characters, so totals such as total purchase amount could not be calculated. The fix was to convert them to normal numbers. Extra unwanted characters (like the currency symbol) were removed first so that only the price remained.
**Business example:** When an Indian retailer pulls prices like "₹1,299" from its website, analysts strip the ₹ sign and comma and store 1299 as a number before computing average selling price.
**Remember:** Strip, then convert. Remove symbols and extra text, then change the data type.

### Normalising the rating column

**Definition:** Normalisation means bringing values into one standard, usable format.
**Class example:** Ratings were scraped as words. You map them to numeric scores: "One" becomes 1, "Two" becomes 2, and so on up to 5. Now the column can be counted, averaged and plotted.
**Business example:** Platforms like Nykaa and Zomato store star ratings as numbers (1 to 5) so they can show average ratings and sort products by rating.
**Exam tip:** Use the phrase "converting categorical text to numerical scores (1, 2, 3, 4, 5)".

### Cleaning in Excel and Power BI

**Definition:** The same transformations can be done without code, using spreadsheet or BI tools.
**Class example:** The faculty said type changes can be handled in **Excel** and **Power BI** as well as in code. Power BI was singled out for string work: extracting **substrings** and **removing specific words** from text. In the spreadsheet route, a value (cell A2) was copied into a single cell to set up a value for plotting and further custom changes.
**Business example:** Many Indian FMCG sales teams clean distributor data in Power Query (inside Excel and Power BI) using steps like "Replace values", "Extract text" and "Change type".
**Remember:** Code is faster for repeat jobs and large data. Excel and Power BI are quicker for one-off cleaning.

### Null values

**Definition:** A null value is a blank or missing entry in a column.
**Class example:** You must check the rating column for blank or null values. Missing data is an important factor in analysis because it can distort averages and counts.
**Business example:** If 30% of products on a marketplace have no rating, an "average rating" chart that ignores them can mislead a category manager.
**Exam tip:** Name the check (`df.isnull().sum()` in Pandas) and say what you will do: drop, fill, or flag the missing rows.

### Extending the CSV

**Class example:** Once you understand the structure of the CSV, you can add more columns to it (for example a numeric rating column or a calculated field). Formulas and specific columns can also be passed to an **API** for further processing.

## KPIs and the dashboard

### Core KPIs

**Definition:** KPIs are the few numbers that tell you how a business is performing.
**Class example:** The class referred to **Average Order Value (AOV)** and **Conversion Rate**, and for the book data, **average price** and **maximum price** (heard as "maximum production").
**Formula:** AOV = Total revenue / Number of orders
**Formula:** Conversion rate = (Number of conversions / Number of visitors) x 100
**Business example:** Quick-commerce firms such as Blinkit and Zepto track AOV closely, because a higher basket value spreads delivery cost and improves unit economics.
**Exam tip:** Always pair a KPI with its formula and a one-line meaning.

### Book data dashboard requirements

**Definition:** A dashboard puts KPIs and charts on one screen so you can read the numbers at a glance.
**Class example:** The dashboard brief was:
- KPI cards: **average price** and **maximum price**
- **Top prices in descending order**
- **Rating distribution:** bar graph of the number of books at each rating (1 star, 2 stars, and so on). In the class data, **1-star ratings had the highest number of books**.
- **Price vs rating plot:** a scatter plot to see whether higher price relates to higher rating
- Option to **download the underlying data as CSV**

The workflow: take the URL response, convert it into a DataFrame, generate the dashboard, and offer the CSV for download.
**Business example:** Amazon sellers in India use Seller Central dashboards that show sales, ratings and price data together, with download options for detailed reports.
**Remember:** Bar graph for counts by category, scatter plot for the relationship between two numbers, sorted table for top values.

## What the faculty stressed

- The end product of data collection is a **CSV file** ready for pre-processing.
- Import libraries correctly and know their roles: **Pandas (`pd`)** for tables, **Matplotlib (`plt`)** for charts.
- Scraping follows a funnel: page structure, raw text, then price and stock.
- Scraped numbers are text until you **convert the data type**. Remove extra characters first.
- Convert word ratings to **numeric scores** (one = 1, two = 2).
- Always check for **null or blank values**, especially in ratings.
- Pagination: **20 records per page**; the first script only covered page one.
- Excel and **Power BI** can do the same cleaning; Power BI handles substrings and word removal well.
- Dashboards should combine **KPIs** (AOV, conversion rate, average and maximum price) with **charts**.

## Practice questions

**Q1.** What is a Python library? Name two libraries used in class and their purpose.
**A:** A library is a set of pre-written code that you import into a project to use its functions. Pandas, imported as `pd`, handles data in rows and columns. Matplotlib, imported as `plt`, creates charts such as bar graphs and scatter plots.

**Q2.** Explain the funnel approach to extracting product data from a web page.
**A:** You first observe the page and capture its HTML structure, then pull out the raw text of each product. From that text you parse specific fields such as price and stock availability. The result is checked by printing the first five rows and then saved as a CSV.

**Q3.** Why must scraped price and rating data be cleaned before analysis?
**A:** Scraped prices come in as text with symbols, so you cannot add or average them until you remove the extra characters and convert them to numbers. Ratings often come as words like "One" or "Two" and must be mapped to 1, 2 and so on. Without this, totals, averages and charts will fail or give wrong results.

**Q4.** What is pagination and how does it affect web scraping?
**A:** Pagination splits records across pages, for example 20 items per page. A scraper that reads only the first URL gets only the first 20 records. To collect the full dataset you loop through the page URLs; 1,000 records at 20 per page means 50 requests.

**Q5.** Define AOV and conversion rate with formulas, and say why an e-commerce firm tracks them.
**A:** AOV = total revenue / number of orders, and conversion rate = conversions / visitors x 100. AOV shows how much a customer spends per order, while conversion rate shows how well the site turns visits into purchases. Together they explain revenue changes, as firms like Blinkit and Zepto do when they push basket size.

**Q6.** Design a dashboard for the scraped book data. Which KPIs and charts would you include?
**A:** Show KPI cards for average price and maximum price, and a table of top prices in descending order. Add a bar graph of book counts by rating (in class, 1-star had the most books) and a scatter plot of price versus rating. Provide a CSV download so others can run further analysis.
