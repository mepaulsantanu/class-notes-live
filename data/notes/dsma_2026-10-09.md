## Why this analysis matters: user drop-off

**Definition:** User drop-off is the point where visitors leave a website, app or video before completing a goal such as a purchase, a sign-up or watching to the end.
**Class example:** The class opened by looking at how certain images and page layouts could be causing users to drop off. The same idea came back at the end as the core objective of CA2: identify drop-offs and suggest fixes based on competitor analysis.
**Business example:** E-commerce players like Myntra and Flipkart run A/B tests on product images and page layouts and track where users exit the funnel, so they can fix the pages that lose the most buyers.
**Remember:** Drop-off is found with data, and fixed with design. Analytics tells you *where* users leave; testing and comments tell you *why*.

## Web scraping

### Purpose and output

**Definition:** Web scraping is the automated collection of data from web pages. The goal is a clean, structured **CSV file** that you can pre-process and analyse.
**Class example:** After the imports ran successfully, the next step was to give the program a web page URL. The code then works out how much data and how many results that page holds.
**Business example:** Indian price comparison sites like Smartprix track product prices across Amazon.in and Flipkart by collecting listing data repeatedly, then show users price history and the cheapest seller.
**Exam tip:** Always state the end product. In this course, the output of data collection is a CSV file ready for pre-processing.

### The extraction funnel

**Definition:** Extraction follows a funnel: observe the page, capture its structure (the HTML elements and their tags or CSS classes), pull out the raw text, then parse out the specific data points you need.
**Class example:** The faculty called the captured page structure "CST" (likely the HTML/CSS structure of the page, i.e. the DOM tree). From that, the code captured:
- **Text** of each product, the main raw source
- **Price**, isolated from the text
- **Stock availability**, whether the item is in stock

The logic counted how many goods were on the **first page** and printed only the **first five rows** (the head of the data, `df.head()`).
**Business example:** A D2C brand like boAt can monitor competitor listings for price and "out of stock" status to spot when a rival runs short and adjust its own ads or prices.
**Remember:** Text first, then price, then stock. Check your result with `head()` before scraping more pages.

### Pagination

**Definition:** Pagination limits the number of records shown per page, so a large list is split across many pages.
**Class example:** The site showed **20 items per page**. You request a specific URL to get the response for a range, such as items **1 to 20**, then move to the next page URL for the next 20. The first version of the code only scraped page one.
**Business example:** Amazon.in search results and Flipkart category pages are paginated, so any scraper or crawler has to loop through page numbers in the URL to collect the full catalogue.
**Formula:** Number of pages = Total records / Records per page (round up). For example, 1,000 books / 20 per page = 50 pages.
**Exam tip:** Mention that scraping only page one gives a sample, not the full dataset. A loop over page URLs fixes this.

## Data cleaning and pre-processing

### Data type conversion

**Definition:** Scraped values often arrive as text (characters). You must convert them to numbers before you can add, average or sort them.
**Class example:** Prices were stored as characters, so totals such as total purchase amount could not be calculated. The fix was to convert them to normal numbers. Extra unwanted characters (like the currency symbol) were removed first so that only the price remained.
**Business example:** When an Indian retailer pulls prices like "₹1,299" from its website, analysts strip the ₹ sign and comma and store 1299 as a number before computing average selling price.
**Remember:** Strip, then convert. Remove symbols and extra text, then change the data type.

### Normalising the rating column

**Definition:** Normalisation means bringing values into one standard, usable format.
**Class example:** Ratings were scraped as words. You map them to numeric scores: "One" becomes 1, "Two" becomes 2, and so on up to 5. Now the column can be counted, averaged and plotted.
**Business example:** Platforms like Nykaa and Zomato store star ratings as numbers (1 to 5) so they can show average ratings and sort products by rating.
**Exam tip:** Use the phrase "converting categorical text to numerical scores (1, 2, 3, 4, 5)".

### Cleaning in Excel and Power BI

**Definition:** The same transformations can be done without code, using spreadsheet or BI tools.
**Class example:** The faculty said type changes can be handled in **Excel** and **Power BI** as well as in code. Power BI was singled out for string work: extracting **substrings** and **removing specific words** from text. In the spreadsheet route, a value (cell A2) was copied into a single cell to set up a value for plotting and further custom changes.
**Business example:** Many Indian FMCG sales teams clean distributor data in Power Query (inside Excel and Power BI) using steps like "Replace values", "Extract text" and "Change type".
**Remember:** Code is faster for repeat jobs and large data. Excel and Power BI are quicker for one-off cleaning.

### Null values

**Definition:** A null value is a blank or missing entry in a column.
**Class example:** You must check the rating column for blank or null values. Missing data is an important factor in analysis because it can distort averages and counts.
**Business example:** If 30% of products on a marketplace have no rating, an "average rating" chart that ignores them can mislead a category manager.
**Exam tip:** Name the check (`df.isnull().sum()` in Pandas) and say what you will do: drop, fill, or flag the missing rows.

### Extending the CSV

**Class example:** Once you understand the structure of the CSV, you can add more columns to it (for example a numeric rating column or a calculated field). Formulas and specific columns can also be passed to an **API** for further processing.

## KPIs and the dashboard

### Core e-commerce KPIs

**Definition:** KPIs are the few numbers that tell you how a business is performing.
**Class example:** The class referred to **Average Order Value (AOV)** and **Conversion Rate**, and for the book data, **average price** and **maximum price** (heard as "maximum production").
**Formula:** AOV = Total revenue / Number of orders
**Formula:** Conversion rate = (Number of conversions / Number of visitors) x 100
**Business example:** Quick-commerce firms such as Blinkit and Zepto track AOV closely, because a higher basket value spreads delivery cost and improves unit economics.
**Exam tip:** Always pair a KPI with its formula and a one-line meaning.

### Book data dashboard requirements

**Definition:** A dashboard puts KPIs and charts on one screen so you can read the numbers at a glance.
**Class example:** The dashboard brief was:
- KPI cards: **average price** and **maximum price**
- **Top prices in descending order**
- **Rating distribution:** bar graph of the number of books at each rating (1 star, 2 stars, and so on). In the class data, **1-star ratings had the highest number of books**.
- **Price vs rating plot:** a scatter plot to see whether higher price relates to higher rating
- Option to **download the underlying data as CSV**

The workflow: take the URL response, convert it into a DataFrame, generate the dashboard, and offer the CSV for download. The scraped pages themselves act as the data source.
**Business example:** Amazon sellers in India use Seller Central dashboards that show sales, ratings and price data together, with download options for detailed reports.
**Remember:** Bar graph for counts by category, scatter plot for the relationship between two numbers, sorted table for top values.

## Collecting social media data with the YouTube Data API

### What an API does

**Definition:** An API (Application Programming Interface) lets your code ask a platform for data in a structured format, instead of scraping the visible page. You send a request with a key and an ID, and the platform returns fields such as views, likes and comments.
**Class example:** After web scraping, the class switched to the **YouTube Data API**, one of the free APIs Google offers through a cloud project, to pull statistics for a video.
**Business example:** Social media agencies in India pull channel and video statistics through the YouTube Data API into reporting dashboards for brand clients, so they do not have to copy numbers by hand from YouTube Studio.
**Remember:** Scraping reads what the page shows. An API gives you the platform's own data in clean fields, within the limits the platform sets.

### Setting up the API key

**Definition:** An API key is a credential that tells Google which project is making the request.
**Class example:** The steps shown in class:
1. Create a project in Google Cloud. The project is saved in the cloud, not on your laptop.
2. From the menu, enable API services and select the **YouTube Data API**.
3. Go to **Credentials** and create an **API key**.
4. Copy the key immediately and paste it into the Colab script. The faculty warned that it disappears quickly if you do not copy it.

(textbook) The YouTube Data API v3 gives each project a free daily quota of 10,000 units, so heavy scripts can run out.
**Business example:** Any Indian startup that shows YouTube content inside its app, such as an edtech platform embedding lesson videos, creates API keys in Google Cloud in the same way.
**Exam tip:** Write the sequence as: project, enable API, credentials, API key, paste into script. Also say that you should keep the key private.

### Using the video ID

**Definition:** A video ID is the unique code for one YouTube video. In a link like `youtube.com/watch?v=abc123XYZ`, the part after `v=` is the ID.
**Class example:** The script needs the **video ID, not the full URL**. You find the ID in the YouTube link and paste it into the ID variable in the script (heard as "variable B").
**Business example:** A brand like boAt that runs many product launch videos would store each video ID in a sheet and loop through them to pull statistics for all launches at once.
**Remember:** Full URL goes to a scraper. Video ID goes to the YouTube API.

## Social media KPIs and engagement

### Core content KPIs

**Definition:** Content KPIs are the numbers that show how a post or video is performing.
**Class example:** The script returned the video's **view count (412 views)**, **comment count (30 comments)** and **like count**. These three were named as the core KPIs.
**Business example:** Brands like Amul and Zomato watch views, likes and comments on each post to judge which creative style gets the strongest response before putting more money behind it.
**Exam tip:** Views measure reach. Likes and comments measure engagement. Say both in an answer.

### Engagement rate

**Definition:** Engagement rate shows how actively an audience responds, as a share of the people who saw the content.
**Class example:** The faculty said engagement rate comes from comments and other interactions, not raw views. With the class numbers, 30 comments on 412 views gives a comment rate of about 7.3%.
**Formula:** Engagement rate = (Likes + Comments) / Views x 100 (textbook; some firms also add shares)
**Business example:** Influencer agencies in India often compare creators on engagement rate rather than follower count, because a smaller creator with high engagement can drive more action for a brand.
**Remember:** High views with low engagement means people saw it but did not care. Comments tell you why.

### The execute, monitor, analyse cycle

**Definition:** An iterative process where you publish, track KPIs, read feedback and refine the next piece of content.
**Class example:** The recommended workflow was: execute an idea, monitor results through views, likes and comments, then read what people say in the comments to refine the strategy.
**Business example:** Netflix India regularly adjusts its social content style after seeing which posts get strong comment threads, then repeats formats that work.
**Exam tip:** Draw it as a loop: Execute, Monitor KPIs, Analyse comments, Refine, Execute again.

## Text analytics for the dashboard

### Sentiment graphs

**Definition:** Sentiment analysis classifies text such as comments into positive, negative or neutral. A sentiment graph shows the share of each.
**Class example:** Sentiment graphs are a required visual in the CA2 dashboard, built from the comments you collect through the API.
**Business example:** Indian brands use social listening tools such as Talkwalker or Brandwatch to track sentiment around launches and spot negative spikes early.
**Remember:** Counts tell you how much people talk. Sentiment tells you how they feel.

### Word clouds

**Definition:** A word cloud shows the most frequent words in a body of text, with bigger font for more frequent words.
**Class example:** Word clouds are the second required visual for CA2. The demonstration showed that you can right-click on the word cloud option to start generating it.
**Business example:** A food delivery brand can build a word cloud of app reviews and see words like "late" or "cold" stand out, which points straight at the drop-off cause.
**Exam tip:** Mention that you should remove stop words (the, is, and) before building a word cloud, otherwise they dominate it (textbook).

## Practice questions

**Q1.** What is a Python library? Name two libraries used in class and their purpose.
**A:** A library is a set of pre-written code that you import into a project to use its functions. Pandas, imported as `pd`, handles data in rows and columns. Matplotlib, imported as `plt`, creates charts such as bar graphs and scatter plots.

**Q2.** Why must scraped price and rating data be cleaned before analysis?
**A:** Scraped prices come in as text with symbols, so you cannot add or average them until you remove the extra characters and convert them to numbers. Ratings often come as words like "One" or "Two" and must be mapped to 1, 2 and so on. You should also check for null values, because blanks distort averages and counts.

**Q3.** What is pagination and how does it affect web scraping?
**A:** Pagination splits records across pages, for example 20 items per page. A scraper that reads only the first URL gets only the first 20 records. To collect the full dataset you loop through the page URLs; 1,000 records at 20 per page means 50 requests.

**Q4.** List the steps to pull statistics for a YouTube video using the YouTube Data API in Colab.
**A:** Create a project in Google Cloud, enable the YouTube Data API and create an API key under Credentials. Copy the key at once and paste it into the Colab script. Then take the video ID from the YouTube link (the part after `v=`), paste it into the script's ID variable and run it to get views, likes and comments.

**Q5.** A video has 412 views and 30 comments. Which KPIs would you report, and how would you judge engagement?
**A:** Report views as reach, and likes and comments as engagement. The comment rate is 30 / 412 x 100, about 7.3%; adding likes to the numerator gives the full engagement rate. You would then read the comments themselves to learn why people responded and refine the next video.

**Q6.** Design a dashboard for a drop-off analysis project like CA2. What would you include?
**A:** Start with KPI cards such as views, likes, comments and engagement rate, pulled through the API. Add a sentiment graph and a word cloud of comments to show how the audience feels and what they talk about. Compare these numbers with a competitor's channel or website, point out where your audience drops off, and give clear suggestions to fix it.
