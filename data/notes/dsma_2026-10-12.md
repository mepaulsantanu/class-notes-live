This session set out the workflow for the upcoming analytics report in Digital and Social Media Analytics. You use GA4 for the analysis part, and Looker Studio covers both analysis and dashboarding. The report follows three steps: clean the data set, calculate the defined KPIs, then import the processed data into Looker Studio and build an interactive dashboard.

## The reporting workflow

### Overview of the three steps

**Definition:** The report follows a fixed pipeline. You clean the raw data set, calculate the KPIs that the brief defines, and then load the processed data into Looker Studio to build an interactive dashboard.

**Class example:** The class laid out exactly this sequence: cleaning the data set, calculating the defined KPIs, and importing the processed data set into Looker Studio for an interactive dashboard.

**Business example:** Digital marketing teams at Indian D2C brands such as boAt and Mamaearth run campaigns across Google, Meta and their own websites. Before a weekly review, an analyst pulls data from each platform, cleans and merges it, computes cost per acquisition and return on ad spend, and presents it in a shared dashboard. The steps are the same ones you will follow.

**Remember:** Order matters. If you calculate KPIs on dirty data, every number on the dashboard will be wrong, however good it looks.

**Exam tip:** When asked to describe an analytics reporting process, write it as a sequence (collect, clean, calculate, visualise, interpret) and justify why each step comes before the next.

### Step 1: Cleaning the data set

**Definition:** Data cleaning means finding and correcting errors in a data set so that analysis gives reliable results. Common tasks (textbook):
- Remove duplicate rows.
- Handle missing values (fill, flag or drop them).
- Standardise formats, such as dates, currency and text case.
- Correct spelling variations in categories (for example "Bangalore", "Bengaluru", "BLR").
- Check for outliers and decide whether they are errors or genuine values.
- Make sure each column has the right data type (number, date, text).

**Class example:** Cleaning is the first step of the report. It is still unclear whether the professor will give everyone the same data set or assign different data sets to individuals, so you should be ready to clean any raw file you receive.

**Business example:** Food delivery platforms such as Swiggy and Zomato receive addresses typed freely by customers. The same locality can appear in many spellings, so location data has to be standardised before any city or area level analysis of orders is meaningful.

**Remember:** "Garbage in, garbage out." The quality of your output can never be better than the quality of your input data.

### Step 2: Calculating the KPIs

**Definition:** A KPI is a metric tied directly to a business objective. In this report the KPIs are "defined", meaning the brief tells you which ones to compute. Typical digital analytics KPIs include (textbook):

**Formula:** Engagement rate = Engaged sessions / Total sessions × 100

**Formula:** Bounce rate (GA4) = 100% minus engagement rate

**Formula:** Conversion rate = Conversions / Sessions (or users) × 100

**Formula:** Click-through rate (CTR) = Clicks / Impressions × 100

**Formula:** Average engagement time = Total engagement time / Number of active users

**Class example:** Calculating the defined KPIs is step 2 of the report, done after cleaning and before building the dashboard.

**Business example:** An e-commerce site like Nykaa cares about conversion rate (how many visits end in a purchase) and average order value. A content site cares more about engagement time and pages per session. The KPI you pick must match the goal of the business.

**Remember:** In GA4, an engaged session is one that lasts longer than 10 seconds, has a key event (conversion), or has at least two page or screen views (textbook). Bounce rate is simply the share of sessions that were not engaged.

**Exam tip:** Always state the formula, put in the numbers, and then interpret the result in one line. A number without an interpretation scores less.

### Step 3: Building the interactive dashboard in Looker Studio

**Definition:** You import the processed data set into Looker Studio as a data source, then add charts, scorecards, tables and controls (date range, drop-down filters) so the viewer can explore the data on their own.

**Class example:** The final step of the report is importing the processed data set into Looker Studio and creating an interactive dashboard.

**Business example:** Agencies in India commonly share live Looker Studio reports with clients in place of static PDF reports. The client opens a link, changes the date range or picks a campaign from a filter, and the charts update instantly.

**Remember:** A dashboard is "interactive" only if it has controls. A page of fixed charts is a static report. Add at least a date range control and one filter.

**Exam tip:** Good dashboard design points to mention: KPIs as scorecards at the top, trend charts in the middle, detailed tables at the bottom, consistent colours, and no more charts than the viewer needs to answer the business question.

## GA4 versus Looker Studio

### GA4 for analysis

**Definition:** GA4 collects and analyses user behaviour on websites and apps. It uses an event-based data model, where every interaction (page view, scroll, click, purchase) is an event with parameters (textbook).

**Class example:** GA4 is the tool designated for the analysis portion of the project.

**Business example:** Google stopped processing data in the older Universal Analytics on 1 July 2023, so every business using Google Analytics, from small Indian start-ups to large retailers, had to move to GA4.

### Looker Studio for analysis and dashboarding

**Definition:** Looker Studio connects to many data sources (GA4, Google Ads, Google Sheets, BigQuery, CSV files) and lets you build calculated fields, blend data and present it visually. It was called Google Data Studio until Google renamed it in 2022 (textbook).

**Class example:** Looker Studio was described as a combination of tools that gives you both the analysis and the dashboarding capabilities.

**Business example:** A marketing team can connect GA4 (website behaviour) and Google Ads (spend) in one Looker Studio report, then create a calculated field for cost per conversion that neither tool shows on its own in the same view.

**Remember:** GA4 is where the data is collected and explored. Looker Studio is where you combine, calculate and present it for decision makers.

## Practice questions

**Q1.** Describe the three-step workflow for the DSMA analytics report and explain why the order matters.
**A:** First you clean the data set, then you calculate the defined KPIs, and finally you import the processed data into Looker Studio to build an interactive dashboard. Cleaning comes first because KPIs calculated on duplicate, missing or badly formatted data will be wrong. The dashboard comes last because it only displays what the earlier steps produce.

**Q2.** Differentiate between the roles of GA4 and Looker Studio.
**A:** GA4 collects and analyses user behaviour on websites and apps using an event-based model. Looker Studio connects to GA4 and many other sources, lets you create calculated fields and blend data, and presents the results as interactive dashboards. In short, GA4 is the analysis tool, while Looker Studio combines analysis with dashboarding.

**Q3.** List any four data cleaning tasks you would perform on a raw marketing data set.
**A:** You would remove duplicate rows, handle missing values by filling, flagging or dropping them, and standardise formats such as dates and city names. You would also check outliers to decide if they are errors or real values, and make sure each column has the correct data type.

**Q4.** A website had 8,000 sessions, of which 5,200 were engaged sessions. Calculate the engagement rate and the GA4 bounce rate.
**A:** Engagement rate = 5,200 / 8,000 × 100 = 65%. In GA4, bounce rate = 100% minus engagement rate = 35%. This means about one in three sessions ended without meaningful interaction, so the landing pages may need work.

**Q5.** What makes a Looker Studio dashboard "interactive"? Give two features you would add.
**A:** A dashboard is interactive when the viewer can change what the charts show without editing the report. A date range control lets the viewer pick any period, and a drop-down filter (for example by channel or campaign) lets them narrow the data. Without such controls, the report is only a static set of charts.

**Q6.** Why should KPIs be "defined" before the analysis starts? Illustrate with an example.
**A:** KPIs must link to a business goal, otherwise you end up reporting numbers that do not help any decision. An e-commerce brand like Nykaa would focus on conversion rate and average order value, while a content site would track engagement time. Defining KPIs first tells you which data to clean and which charts the dashboard needs.
